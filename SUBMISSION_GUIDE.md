# SIH 2026 submission checklist

Before sharing this repository, confirm:

- The repository is public and opens while logged out.
- `README.md` contains the PS ID and title, problem, solution, features, stack, working setup instructions, team roles, and result overview.
- `assets/screenshots/` contains 4–6 representative, final-state screenshots.
- The final presentation is in `submission/`, or its public viewer link is in `submission/PRESENTATION.md`.
- A public demo-video link is added to `submission/DEMO.md` when available.
- No `.env`, keys, passwords, tokens, or private credentials are committed.
- Backend tests and the frontend production build pass from a clean checkout.

This structure follows the official-style SIH reference template while retaining the project's separate `backend/` and `frontend/` application folders.
